# DROP统一版小批量实测与接口补正

本次是诊断小实验，不是正式全量成绩：从固定Search200题确定互斥的24题探索、12题确认；探索每题一次、确认每题两次，800题Test未使用。确认题曾用于第一批基线重复，未用于本次候选选优。

确认F1提高9.03个百分点；最佳两遍分别91.67%、83.33%。相同确认题次的执行token为基线12,896、最佳45,598（约3.54倍）。样本小且有运行波动，不能推断全量泛化提升。

首批12次提案均被拒绝，没有形成新有效候选，其重复基线分数差不能算优化收益。补充user接口说明后，第二批形成3个完整有效候选；另6次工具提案因缺少inputSchema被拒绝，没有F1。实际system提示词及其hash保持冻结。

实测发现并补正：

1. Context.UPDATE和COMPRESS的原生输出是直接`{items}`，静态字段表误写成`context`，会放过错路径、拒绝合法路径；已修正，并补齐Cache.WRITE的`key`字段。
2. Memory/Cache写入是实际数据消费者，应遍历其上游输入；原消费链检查可能把实际写入状态的数据误判为unused，已修正。
3. evidence必须数组、checker反馈引用不同于说明文字、工具inputSchema必填等错误反馈过于简略。已补全user接口指南和定位信息，保留严格校验，不静默改写模型提案或放宽system边界。

覆盖验证：

- 271项离线Node测试通过，新增回归覆盖真实Context输出和状态写入消费链。
- 实际运行检索+Context变换、生成工具+观察、Memory六操作+Cache、Loop反馈、Deliberate+Reflect、Trajectory链，20类节点均有真实执行证据。人工构造组合不参与F1选优。
- 第二批120条批量题次无运行时工程失败；37条非满分题次全部保留并审计。
- 独立重算120条F1，零差异；通过最终补正执行器离线重放同一批原始模型响应，120条预测零差异，重放不调用网络。
- 全部120条最终模型原始输出与实际提交答案一致；剩余失分没有发现接收/解包/转换导致的丢失。最佳确认仍有距离单位表达和年龄组选择错误，属于模型/任务表达问题。

真实调用、私有逐题参考、原始响应、定义和冻结源码保存在本地实验产物中，没有上传数据或参考答案。这些检查证明本次覆盖范围通过，不证明所有输入和分支永无bug。
